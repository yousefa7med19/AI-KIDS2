## Responsive breakpoints

- Desktop: above 1024 px
- Tablet: 701–1024 px
- Mobile: 700 px and below
- Small mobile refinements: 420 px and below

## Future component policy

Reusable sections should keep stable class names. New pages should reuse the brand colors, typography, button styles, border radii, and spacing system.
